## FAQ

### What is XCutors?

XCutors is a Windows desktop application that bundles multiple popular Roblox Lua script executors (Volt, Synapse Z, Potassium, Wave) together with a universal loader called xcutorsLoader, allowing you to install, manage, and switch between them from a single interface.

### Is XCutors free to use?

The xcutorsLoader itself is free and open-source. However, some of the bundled executors may require their own license keys or subscriptions, which are obtained separately from their respective developers.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11, 64-bit editions only. ARM-based Windows devices are not currently supported.

### Why does my anticomponent flag XCutors or the executors?

Because these tools inject code into the Roblox process, most anticomponent engines flag them as potentially unwanted programs. You may need to add the XCutors installation folder to your anticomponent exclusion list. Always download from the official GitHub Releases page to ensure file integrity.

### Can I use multiple executors at the same time?

No. Only one executor can be attached to the Roblox process at a time. The xcutorsLoader will automatically detach the current executor before attaching a new one if you switch.

### How do I update the executors?

The xcutorsLoader includes a built-in update checker. When you launch the loader, it will notify you if any of the installed executors have newer versions available. You can also check manually under Settings > Updates.

### Where are my saved scripts stored?

Saved scripts and configuration files are stored in %AppData%\XCutors\ by default. You can change the storage directory under Settings > Preferences > Script Library Path.

### The executor fails to attach or crashes. What should I do?

First, ensure Roblox is running and you are in an active game session. Then try running xcutorsLoader as Administrator. If the issue persists, check the execution logs under the Logs tab for error details and visit our GitHub Issues page for community troubleshooting.

### Does XCutors support script hub integrations?

Yes. xcutorsLoader supports loading scripts from popular script hubs and allows you to add custom hub URLs under Settings > Script Hubs. Hub scripts appear alongside your local library in the script browser.

### How do I report bugs or request features?

Please open an issue on the GitHub repository. Provide your Windows version, the executor you were using, steps to reproduce the problem, and any relevant log output. Feature requests are also welcome via the Issues page with the 'enhancement' label.
